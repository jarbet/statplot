# statplot: Convenient Tools for Generating Standard Statistical Plots

statplot is an R package designed to simplify the creation of common
statistical plots. It provides convenient wrapper functions for
generating clean, publication-ready visualizations with minimal code.
Whether you’re exploring data, performing model diagnostics, or
presenting results, statplot helps you focus on analysis rather than
plotting details.
